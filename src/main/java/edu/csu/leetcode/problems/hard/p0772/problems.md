# 772. 基本计算器 III（困难）

给定一个字符串 `s`，请实现一个基本计算器，计算该字符串表示的数学表达式，并返回计算结果。

表达式支持：

- 非负整数（可以是多位数）。
- 四种运算符：`+`、`-`、`*`、`/`。
- 圆括号：`(` 和 `)`，支持嵌套。
- 运算遵循正常的数学优先级：括号优先，其次乘除，最后加减。
- 整数除法的结果向零截断，例如 `-7 / 2 = -3`。

保证输入表达式合法，所有中间计算结果均在 32 位有符号整数范围内。

不能使用 `eval()` 等直接计算字符串表达式的内置函数。

## 示例

**示例 1：**

```text
输入：s = "1+1"
输出：2
```

**示例 2：**

```text
输入：s = "6-4/2"
输出：4
```

**示例 3：**

```text
输入：s = "2*(5+5*2)/3+(6/2+8)"
输出：21
```

## 提示

- `1 <= s.length <= 10^4`
- `s` 只包含数字和 `+`、`-`、`*`、`/`、`(`、`)`。
- `s` 是合法的数学表达式。
